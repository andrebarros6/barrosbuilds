## This week in AI

**Google AI Studio now builds Android apps.** The Build agent writes a Kotlin app with a Firestore database, Google sign-in and Gemini calls, runs it in an emulator, and publishes it to your own Play library. A working prototype on your phone without opening Android Studio. Read the code it writes before you trust it. [Google](https://developers.googleblog.com/build-full-stack-android-apps-with-gemini-in-google-ai-studio/)

**Gemini 4 Hydrogen is in the Gemini API.** A faster, cheaper Gemini, pitched at robotics but callable like any other model as `gemini-4-hydrogen`. Google's post gives no per-token price and doesn't say whether it's a preview. Check both before you build on it. [Google](https://developers.googleblog.com/gemini-hydrogen-for-robotics/)

**How Codex fences in its agent.** Not a launch: an OpenAI engineering post on how Codex limits the commands its agent can run, and the `codex sandbox` command that applies the same limits to your own. Worth twenty minutes if you let an agent run commands on your machine. [OpenAI](https://openai.com/index/inside-the-codex-sandbox/)

**Watching agents from their logs.** Google's Agent Anomaly Detection, which flags unusual agent behaviour from traces, now takes agents running on AWS, Azure or your own servers, if they're built with its ADK. Private preview only. The idea is the part to keep: you can check what an agent did without trusting its own account of it. [Google](https://developers.googleblog.com/agent-anomaly-detection-safeguarding-agents-across-other-clouds/)
